# Partnerlogók a „Vállalati tapasztalat” blokkhoz

A blokk (`src/components/Experience.tsx`) a `src/lib/site.ts` EXPERIENCE listája szerint
jeleníti meg a logókat (`showLogos: true`), fájlonként ellenőrizve, hogy létezik-e itt.
Ha bármelyik fájl hiányzik, a blokk szöveges felsorolásra vált.

Logóhasználati engedély: a megbízó 2026-09-08-án jelezte, hogy a felsorolt szervezetektől
rendelkezésre áll. Az engedélyek dokumentumait (kitől, mikor, milyen feltétellel) érdemes
ebben a mappában vagy a cég iratai között megőrizni.

Fájlok (160 px magas, körbevágott, átlátszó hátterű PNG-k):
spar.png, hbo.png, prangl.png, audi.png, isg.png, gablini.png, dr-oetker.png, rbl.png, oeconomus.png

Nyers eredetik és a feldolgozott másolatok: `logos-source/` (nem kerül az oldalra).
